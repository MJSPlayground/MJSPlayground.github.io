Política de privacidad de FlowCash

Fecha de última actualización: 8 de abril de 2026. Este texto se ha preparado como una base profesional para la fase actual del proyecto y conviene revisarlo antes de una publicación comercial definitiva.

Volver a FlowCash Contacto

Resumen rápido

FlowCash está pensada para recopilar solo la información necesaria para prestar sus funciones de finanzas personales.

No se venden datos a terceros y la intención del proyecto es minimizar la exposición de la información del usuario.

Aviso: esta política es un texto provisional de referencia para la web informativa y la futura app FlowCash. Antes de una publicación definitiva en tiendas o entornos comerciales conviene revisarla y ajustarla a la implementación real.

1. Responsable del tratamiento

El responsable del tratamiento de los datos relacionados con FlowCash es MJS Playground. Para cualquier consulta sobre privacidad, soporte o ejercicio de derechos, puedes escribir a mjsplayground90@gmail.com.

2. Datos que puede recopilar FlowCash

En función de las funcionalidades disponibles en cada versión, FlowCash podría tratar datos como los siguientes:

  • Información introducida voluntariamente por el usuario, como movimientos económicos, categorías, presupuestos y objetivos de ahorro.
  • Datos técnicos básicos del dispositivo o registros de error cuando sean necesarios para mantener la app estable y segura.
  • Datos de contacto facilitados de forma voluntaria cuando el usuario escribe para soporte, sugerencias o incidencias.

3. Finalidad del tratamiento

La información tratada se utilizará para:

  • Permitir el funcionamiento normal de la app y sus herramientas de finanzas personales.
  • Mejorar la experiencia de uso, corregir errores y mantener la seguridad del servicio.
  • Responder consultas, solicitudes de soporte o comunicaciones realizadas por el usuario.

4. Base jurídica

La base jurídica para el tratamiento dependerá del contexto: ejecución del servicio solicitado por el usuario, consentimiento cuando sea necesario y, en determinados supuestos, interés legítimo para mantener la seguridad técnica y mejorar el producto.

5. Conservación de la información

Los datos se conservarán durante el tiempo necesario para prestar la funcionalidad correspondiente, atender incidencias y cumplir posibles obligaciones legales. Cuando ya no sean necesarios, se eliminarán o anonimizarán de forma razonable.

6. Destinatarios y terceros

FlowCash no está planteada para vender datos personales ni cederlos con fines publicitarios. En caso de ser necesario para el funcionamiento del proyecto, podrían intervenir proveedores técnicos vinculados al alojamiento, mantenimiento o soporte, siempre bajo condiciones adecuadas de confidencialidad.

7. Seguridad

Se aplicarán medidas técnicas y organizativas razonables para proteger la información frente a accesos no autorizados, alteraciones o pérdidas. Aun así, ningún sistema es completamente infalible, por lo que la seguridad absoluta no puede garantizarse.

8. Derechos de las personas usuarias

Las personas usuarias podrán solicitar acceso, rectificación, supresión, oposición, limitación del tratamiento o portabilidad de sus datos cuando corresponda. Para ello, bastará con contactar mediante el correo indicado en esta página.

9. Menores de edad

FlowCash no está orientada de forma específica a menores de edad. Si se detectara un tratamiento no deseado de datos de menores sin la autorización necesaria, se adoptarían las medidas oportunas para su eliminación.

10. Cambios en esta política

Esta política podrá actualizarse a medida que evolucione la app o cambien sus funcionalidades. Cuando eso ocurra, se publicará una versión revisada con una nueva fecha de actualización.
